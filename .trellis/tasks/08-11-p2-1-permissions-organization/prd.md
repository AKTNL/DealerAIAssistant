# P2-1 完整用户权限与组织范围

## Goal

建立真实用户身份、可撤销会话、可配置 RBAC、组织层级数据范围和可运营的管理界面，使所有业务 API、SSE、Agent 工具、知识和报告共享同一授权事实源。

## Child Tasks

1. **P2-1A 身份、RBAC 与会话基础**：先替换 shared-key 身份，完成会话、功能权限、管理 API、审计和业务授权收敛。
2. **P2-1B 组织树与数据范围**：在稳定身份之上增加组织授权和强制数据范围过滤。
3. **P2-1C 权限与组织管理界面**：在 A/B 的管理 API 稳定后交付可视化运营入口。

## Dependency Order

`P2-1A -> P2-1B -> P2-1C`

## Acceptance Criteria

* [ ] 匿名、无功能权限、无组织范围和跨范围访问分别有后端拒绝回归。
* [ ] 权限或范围变更在下一次请求立即生效。
* [ ] 页面入口与后端授权一致，但安全性不依赖前端隐藏。
* [ ] 所有敏感管理操作和会话安全事件可审计且不记录秘密。

## Out of Scope

* tenant 级隔离属于 P2-2。
* SSO、service account 和自助邮件找回密码另立任务。
