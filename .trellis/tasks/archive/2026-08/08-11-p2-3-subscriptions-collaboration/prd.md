# P2-3 订阅、推送和协作

## Goal

让有权限的用户按 tenant 和组织范围订阅报告，通过可靠任务生成并投递到受控通道，同时对报告进行状态管理和协作处理。

## Child Tasks

1. **P2-3A 报告订阅与调度定义**：订阅配置、范围、频率、时区和生命周期。
2. **P2-3B 可靠任务执行**：持久化 job、幂等、重试、并发和失败恢复。
3. **P2-3C 通知投递通道**：通道抽象、适配器、凭据和回执。
4. **P2-3D 报告协作工作流**：状态、负责人、评论/历史和协作通知。

## Dependency Order

`P2-2B -> P2-3A -> P2-3B -> P2-3C`，P2-3D 在 P2-3A 后启动。

## Acceptance Criteria

* [ ] 订阅创建、执行、投递和协作均受当前权限、tenant 和组织范围约束。
* [ ] 同一计划窗口不会重复生成或重复投递。
* [ ] 失败任务可重试、可诊断、可人工补偿且保留审计。
* [ ] 禁用用户、撤销权限或删除订阅后不会继续生成未授权内容。

## Out of Scope

* 首个投递通道之外的渠道按适配器扩展，不在一个任务中全量实现。
* 不实现通用 BPM/工单平台。
