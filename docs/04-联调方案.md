# 联调方案

## 目标

定义前端、后端、数据、模型服务和测试数据之间的联调方式。联调文档要帮助开发者快速启动本地环境、定位接口/SSE/数据问题，并为后续测试环境和真实模型服务接入留出扩展路径。

## 当前本地启动链路

### 后端

```powershell
cd backend
$env:APP_ACCESS_KEY="local-demo-key"
$env:APP_SESSION_SECRET="local-demo-session-secret-at-least-32-chars"
$env:APP_API_KEY="local-demo-internal-api-key"
mvn "-Dfrontend.skip=true" spring-boot:run
```

默认地址：`http://localhost:8081`

### 前端

```bash
cd frontend
npm ci
npm run dev
```

默认地址：`http://localhost:5173`

Vite 默认把 `/api` 代理到 `http://127.0.0.1:8081`。

## 必需环境变量

| 变量 | 用途 | 当前要求 |
| --- | --- | --- |
| `APP_ACCESS_KEY` | 前端登录访问密钥 | 本地必须显式设置 |
| `APP_SESSION_SECRET` | session token HMAC 密钥 | 至少 32 字符 |
| `APP_API_KEY` | 内部受保护 API key | 本地必须显式设置 |
| `APP_CORS_ALLOWED_ORIGINS` | CORS 来源 | 默认允许 Vite 本地地址 |
| `APP_EXCEL_PATH` | Excel 数据源 | 默认 classpath 样例 |
| `APP_EXCEL_FALLBACK_ENABLED` | 工作簿失败时是否回退样例 | demo 默认 true，prod false |
| `APP_MODEL_BASE_URL` | 默认模型服务地址 | 可选 |
| `APP_MODEL_API_KEY` | 默认模型 API key | 可选 |
| `APP_MODEL_NAME` | 默认模型名 | 可选 |
| `APP_MODEL_ALLOWED_HOSTS` | 模型服务 host allowlist | 真实联调建议显式设置 |
| `APP_MODEL_ALLOW_PRIVATE_HOSTS` | 是否允许 localhost/内网模型地址 | 默认 false |

## 联调场景

### 1. 登录链路

| 步骤 | 期望 |
| --- | --- |
| 打开前端 | 显示登录页 |
| 输入 `APP_ACCESS_KEY` | `POST /api/auth/verify` 成功 |
| 成功登录 | session token 存入 sessionStorage，进入聊天页 |
| 错误密钥 | 显示登录错误，不进入聊天页 |

### 2. 数据导入链路

| 步骤 | 期望 |
| --- | --- |
| 后端启动 | 校验 5 个必需 sheet 并导入 H2 |
| 工作簿可用 | `GET /api/data-status` 显示非 fallback |
| 工作簿不可用且 fallback enabled | 使用内置样例，前端显示警告 |
| `prod` fallback disabled | 启动失败，不伪装成真实导入成功 |

### 3. 聊天 SSE 链路

| 事件 | 期望 |
| --- | --- |
| `step` | 展示分析步骤和状态 |
| `analysis_metadata` | 在正文前提供场景、范围、指标口径、来源、限制、置信度 |
| `progress` | 作为加载占位步骤 |
| `message` | 流式 Markdown 文本块 |
| `done` | 完成并解除发送状态 |
| `error` | 显示错误并允许用户恢复 |

### 4. 模型服务联调

| 模式 | 期望 |
| --- | --- |
| 未配置模型 | 规则引擎直接生成可复现回答 |
| 配置模型成功 | 后端生成事实锚点，再交给模型润色 |
| 模型连接失败 | 前端显示连接失败，规则路径仍可用于业务分析 |
| host 不在 allowlist | 后端拒绝连接，避免 SSRF 风险 |

### 5. 原始数据和指标 API

| 接口类型 | 验证点 |
| --- | --- |
| `/api/v1/data/*` | 过滤参数、数据权限、`X-API-Key` |
| `/api/*/metrics` | 指标口径和聊天回答一致 |
| `/api/*/details` | 分页参数、排序、最大 pageSize |
| `/api/data-status` | 登录态、回退状态、质量汇总 |

## 目标联调环境

| 环境 | 用途 | 数据 | 模型 |
| --- | --- | --- | --- |
| local | 开发自测 | 样例 Excel 或本地文件 | 可选，本地或企业网关 |
| test | 自动化和联调 | 固定测试数据集 | mock 或受控模型 |
| staging | 业务验收 | 脱敏真实数据 | 真实模型网关 |
| prod | 生产 | 真实数据 | 生产模型网关 |

## 待拆任务

| 优先级 | 任务 | 验收 |
| --- | --- | --- |
| P0 | 本地联调脚本整理 | 一条文档路径能启动前后端并登录 |
| P0 | SSE 契约测试设计 | 事件顺序和字段可回归 |
| P0 | 模型服务 allowlist 联调 | 成功、失败、拒绝私网地址都有明确结果 |
| P1 | 数据导入失败联调 | fallback 和 strict 模式都能验证 |
| P1 | API 鉴权联调 | session token 和 `X-API-Key` 边界清楚 |
| P1 | 测试环境配置模板 | 环境变量和数据源不依赖个人机器 |
| P2 | 一键健康检查 | 登录、数据状态、模型测试、SSE smoke test |

## 故障定位清单

| 现象 | 优先检查 |
| --- | --- |
| 前端无法访问后端 | Vite proxy、后端端口、CORS |
| 登录失败 | `APP_ACCESS_KEY`、session secret |
| 数据接口 401/403 | session token 或 `APP_API_KEY` |
| 聊天一直 loading | SSE 是否返回 `done` 或 `error` |
| 分析结果为样例数据 | `GET /api/data-status` 的 fallback 状态 |
| 模型测试失败 | base URL、host allowlist、API key、模型名 |
| 图表不显示 | Markdown fence、chart JSON、前端渲染降级 |
